# 画布操作

让 Agent 直接操作项目中打开的画布，搭建和整理节点流程。

## 使用方式

先打开目标项目的画布，再向 Agent 描述希望完成的操作。
例如：“把当前画布整理整齐”“添加一个文本节点写入这段分镜”“把这张参考图接到视频生成节点”。
Agent 会先读取实际节点和可用能力，再执行操作；已有节点可以继续复用。

## 支持的功能

- 新建、切换和重命名画布。
- 添加节点；批量移动、重命名、选择和删除节点，一次可处理多个节点。
- 将工作区已有的图片、视频批量放入素材节点，复用已有相同文件输出的节点，不触发生成。
- 批量连接兼容的节点端口，批量删除指定连线。
- 用文字 AI 分析整张画布的语义分组，在窗口确认后重新分组并按连接排列，支持一步撤销；也可只调整视图展示指定节点。
- 调用节点提供的功能，例如修改文本、设置提示词或生成媒体；具体以该节点支持的功能为准。

需要保持目标画布可用。新增节点的类型取决于当前安装的节点插件，连线也须满足节点的输入要求。
独立媒体任务可先交付进度；要求完整准备、审查后交付或等待上游后继续时，Agent 使用实际等待能力，在同轮取得结果并继续，减少反复催办。等待不启动新生成，可停止，页面须保持连接；中断后按保存的制作交接和现场状态恢复。`waitCanvasNodes`单次最多50秒，内置`waitForCanvas`可合并最长30分钟等待。
图片和视频生成节点的 `node:generateImage`、`node:generateVideo` 可在同一次调用中传入 `prompt` 与该节点 `setConfig` 支持的配置字段，也可传 `{}` 沿用当前设置。`setPrompt` 可同时更新配置，但不会启动生成；参数、模型能力和未完成任务校验均继续生效。尺寸、比例及模式从 `getConfig` 获取，不自行推算；已有任务先查询或恢复，不自动重新生成。
智能整理会调用已配置的文字模型，不触发媒体生成。分组方案需要用户在窗口确认，取消时保留原布局。
本工具没有配置项，无需单独填写 API Key；媒体生成所需配置由对应供应商提供。
