# 字幕

连接一个视频或音频，使用本地助手中的官方 OpenAI Whisper 转录。云端保留节点、字幕编辑和结果存储，识别只在选定的本地托盘执行。请升级助手到 0.6.0，在“批量字幕”检测 GPU、内存和磁盘后安装推荐模型；环境与权重全部从官方源下载，站点无镜像。模型可选 auto 按本机资源推荐，语言留空自动识别。Python 路径在托盘配置，服务器不安装 Python 或模型。

生成与导入 SRT 只更新草稿。分段表使用 `HH:MM:SS,mmm` 时间格式，可修改时间和文本、添加或删除分段。点击“保存字幕”后写入节点目录的 subtitle.srt 并更新 STRING 输出；未保存的草稿保存在画布中。导出仅导出成功保存的字幕，草稿有修改时须先保存。

Agent 使用 generateSubtitle 启动后台任务，按需查询 getGenerationStatus，确认后调用 saveSubtitle；setSubtitle 解析并保存给定 SRT。cancelGeneration 显式取消本地任务；关闭画布不会取消已提交识别。AI 确定的错误自动修正，不确定项、失败或超时仅记录并继续交付 SRT。重新打开节点可恢复已有任务查询，结果回传失败时本机保留字幕并重传，不重新识别。保存冲突保留草稿及旧输出。
