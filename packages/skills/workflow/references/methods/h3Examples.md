# H3 完整示例：连续镜头、真实切镜与声音

这些是虚构教学简报对应的完整六段正文，展示如何把[H3 适配](../h3Director.md)落实为可写入的文稿，不提供额外导演规则或效果保证。场景、人物、对白和规格只属于各自示例；实际作品沿用用户剧本。视频反解另按[视频反解](videoReverse.md)取得原片证据。

每例假定所列图片已实际采用、按当前节点真实映射取得标签，模型支持指定时长与声音。实际执行先用 `node:getConfig` 核对 `references.id`，登记 `subjects` 的 `id/name/references`，不把示例序号当真实引用 id。引用不齐或模式不符时保留草稿；不能照抄不存在的标签并称可提交。人物多形态说明与一般素材用途见[资产制作](../assets.md)。

## 例一：十秒内完成取钥匙，一镜到底

教学简报：阿宁坐在木桌旁，右手拿起桌上唯一一把黄铜钥匙，收在右手掌心，随后看向仍关闭的门。不站起、不解锁、不出现其他人物，全段连续。仅钥匙离开木桌时的轻微摩擦声，无对白或配乐。已确认写实风格与左侧窗光，时长十秒。

输入映射：`<Picture 1>` 是阿宁的身份与当前服装参考；`<Picture 2>` 是含桌、门和左侧窗的场景；`<Picture 3>` 是钥匙结构参考。主体 1 只登记图片 1，场景和钥匙通过保留分析与当前镜头落实，不登记成额外人物。此处图片是普通参考，不是强制首帧。

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的阿宁，身份、发型、体型和当前服装以该图为准。

summary:
[reference generation] 十秒连续镜头：阿宁从木桌上拿起唯一的黄铜钥匙，收在右手掌心，随后看向仍关闭的门。

retention_analysis:
<Picture 1> 仅固定 <Subject 1> 的身份与当前服装，保留五官、发型、体型、衣服形制和本色，不复现参考板布局或背景。
<Picture 2> 固定木桌、关闭的门和左侧窗的空间关系，全段保持门关闭，不沿用图中可能附带的人物。
<Picture 3> 仅固定唯一钥匙的形制、黄铜材质及相对手掌的大小，不复制展示背景或增加第二把钥匙。

detailed_description:
写实画面，光从既定左侧窗进入，木桌保留哑光木纹，黄铜钥匙保留窄高光；服装本色不因综合色调改变。
[Shot 1] 摄影机从桌侧接近阿宁肩部的高度拍摄中近景，阿宁的脸、右手、桌面钥匙和后方关闭的门均在画面可读范围。阿宁保持坐姿，右手伸向桌上唯一的钥匙，拇指和食指接触匙柄后捏稳，将钥匙完整提离桌面；钥匙离桌时只有轻微摩擦声。她把钥匙收进同一只右手的掌心，不换手，随后看向门，门仍关闭。摄影机在取钥匙过程中沿原拍摄方向极缓慢推进，持续保留脸、右手和钥匙接触点，钥匙离桌后逐渐减速，停在脸与持钥匙右手仍同时入画的较近构图。她看向门时保持这一落点，不切镜、不跳回远景。片段结束时她仍坐着，钥匙在右手，桌上原钥匙位置已经空出，门保持关闭。

overall_soundscape:
仅钥匙离开木桌时的轻微摩擦声，无对白，不添加其他拟音。

non_diegetic_music:
N/A
```

伸手、接触、拿起、收掌和看门是同镜内的动作进程；不因五个动作写成五个 Shot。若用户原文要求固定机位，删去本例的推进并保持固定构图，不能把教学运镜当成原稿事实。

## 例二：十五秒双人递信，七秒处明确切镜

教学简报：阿宁在桌左、小林在桌右，门窗与桌的空间关系已定。阿宁左手把唯一一封未拆的信放到桌中并松手，说“路上小心。”；七秒处按已确认方案切到小林一侧，小林右手接起同一封信，说“我会回来。”，不拆信、不离座。保留左侧窗光、纸擦桌面的轻声，无配乐或额外对白。时长十五秒；这次切镜是简报明确要求，不由时长推导。

输入映射：`<Picture 1>` 固定阿宁身份与当前造型，`<Picture 2>` 固定小林身份与当前造型，`<Picture 3>` 固定桌、门、窗的场景关系，`<Picture 4>` 固定未拆信封结构。主体 1 登记图片 1，主体 2 登记图片 2；说话人 S1 为阿宁、S2 为小林，全段保持映射。原信件内容未知，不补写。

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的阿宁，保持该图身份与当前服装。
<Subject 2> 是 <Picture 2> 中的小林，保持该图身份与当前服装。

summary:
[reference generation] 十五秒双人递信：阿宁把未拆信封放到桌中并说“路上小心。”，七秒处切镜，小林接起同一封信并回答“我会回来。”。

retention_analysis:
<Picture 1> 只控制阿宁的五官、发型、体型及当前衣着，全段保持同一身份，不复制参考板背景。
<Picture 2> 只控制小林的五官、发型、体型及当前衣着，全段保持同一身份，不与阿宁的外观融合。
<Picture 3> 控制桌、门和左侧窗的空间关系及既定窗光，两人始终隔桌而坐；切镜不交换两人的世界位置。
<Picture 4> 控制唯一信封的形制、材质和未拆封状态，信的内容未知，不显示信纸或新增可读文字。

detailed_description:
保持已确认写实风格和左侧窗光，面部暗侧仍可辨认，衣服与信封本色不变。两人不离座，信封保持唯一且未拆。S1 为阿宁，S2 为小林。
[Shot 1] 桌侧双人中景，阿宁在画面左、小林在右，两人的脸、阿宁左手和桌中放信位置同时可见。阿宁左手把未拆信封平放到桌中，指尖松开并离开信封，小林此时尚未伸手。信封接触并滑过木桌时发出轻微纸擦声。阿宁看向小林，<Subject 1> (S1) 说：<d>[Chinese]路上小心。</d> 摄影机保持固定，完整保留放下、松手及说话过程。切镜前信封已静置桌中，阿宁左手已经离开，小林右手尚未接触信封。

[Shot 2] At 00:07.000, 切到同一互动轴线一侧偏向小林的中近景，保留小林的脸、右手、桌中信封及阿宁在左侧的局部位置关系，不越轴。开镜时信仍在桌中，阿宁的手已离开。小林右手伸向信封，拇指与其余手指捏稳信封边缘后，将同一封信提离桌面并保持在右手；接触时只有轻微纸擦声。他看向阿宁，<Subject 2> (S2) 说：<d>[Chinese]我会回来。</d> 摄影机维持固定构图，不插入新的特写或反应镜头。结束时两人仍坐在原位，信封在小林右手且封口完好，桌中原位置空出。

overall_soundscape:
保留两句原对白及信封接触木桌的轻微纸擦声，不新增对白、环境拟音或转场声。

non_diegetic_music:
N/A
```

第二镜从第一镜已经完成的“放下并松手”继续，不能在开镜时把信直接放入小林手中。两句完整对白只在各自发生的详细描述内使用 `<d>`，不在保留分析中重复对白协议。

## 画外声音的局部写法

若用户原文另有旁白“那天，我没有拆开那封信。”，而 S1/S2 已绑定画内人物，可在实际发生的镜头内另写：

```text
narrator (S3)：<d>[Chinese]那天，我没有拆开那封信。</d> 这是独立画外声源，画内人物不为这句旁白张嘴。
```

该短例只示范新增独立声源的绑定；无旁白原文时不能加入作品，不因旁白内容而替未知信件添加答案。原文已经指定的 OS/VO 与说话人关系继续保留；它属于详细描述中的声音事件，不替代完整六段正文，也不要求额外音色样本。
