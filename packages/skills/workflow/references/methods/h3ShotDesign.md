# H3镜头设计表达

在用户要求创作分镜、电影感或需要把模糊摄影意图落实时使用。本方法吸收创作分镜中的观看任务、六要素和具体词汇选择，沿用主PART A与h3Director的剧情、能力、真实引用和六段正文；不增加第二套导演流程。

## 用观看顺序选择镜头

先决定观众在本段需要看清的事：人物与空间、关键动作的因果、动作结果或反应。可以从建立关系进入动作细节，再以结果收束，也可由细节揭示全貌；根据当前剧情取舍，不固定三镜、四镜或每镜几秒。

同一视点与连续运动能完成观看任务时，保留一个镜头；确需新视角或信息揭示才切镜。时间块是动作进度，不自动变成Shot；摄影镜头也不自动变成独立生成段。先按实际模型与任务确认生成段，再在其中组织镜头。

## 把六要素写进当前镜头

检查这次镜头实际需要的主体与状态、动作和物理过程、环境空间、风格及光色、摄影控制、声音要求。已有信息直接继承，只补缺失且有作用的表达；正式稿合入H3已有字段，不把六要素再输出为另一套标题。

主体与摄影机分别描述。例如“人物向前走，摄影机从侧方平行跟随并保持双手入画”，不能只写“动态跟拍”。需要一次推进时，写清从哪里开始、沿什么方向移动、关键动作何时减速、最后停在哪个景别与构图，不能推进后无切镜地跳回远景。

每个时间范围保留清楚的主要摄影控制。固定中景、轻缓推轨、后拉揭示空间、横移跟随、有限弧形环绕、由一个既有对象摇向另一个对象，按观看任务选择；运动强弱与表演相容，不为专业感堆器材名、毫米数和相反运动。

### 从观看目的选到具体写法

下表是按需取用的短例，只在原剧情确有相应人物、物件和空间时使用；不组成固定镜头顺序。

| 要看清什么 | 可执行的摄影表达 | 注意事项 |
|---|---|---|
| 人物与出入口的关系 | 从室内一角保持全景，让人物、桌和门同时可见，人物走向门时不改变机位 | 以空间和行动路线为重点，不默认切到特写 |
| 双人关系及递物过程 | 桌侧双人中景，双方脸、交互的手和桌中物件同时入画 | 手部近景只在确需看细节且不丢掉施事关系时使用 |
| 一次动作逐渐成为重点 | 从人物腰部以上中景沿原轴线缓慢推近，手接触物件前减速，停在脸与双手仍可见的近景 | 推轨改变机位和透视；不要推近后突然跳回全景 |
| 仅改变画面取景范围 | 摄影机位置固定，缓慢变焦收紧到既有对象，保留原观察方向 | 变焦不等于摄影机向前移动，也不自动产生推拉变焦效果 |
| 人物持续向前走 | 摄影机在人物前方同速后退，保持正面中景及其前进方向 | 人物前进、摄影机后退分别写清；路线应有可通行空间 |
| 人物移动时保留手上物件 | 摄影机位于人物侧方平行移动，维持同一侧中景，让持物的手持续入画 | 不把人物位移误写成原地摇摄 |
| 从局部揭示已有空间 | 从前景门框边缓慢横移，门框退出遮挡，露出原本在门后的桌与人物，停在可读的空间关系上 | 揭示已有对象，不凭运镜增添人物或房间 |
| 视线由近处转向远处 | 机位固定，先对焦前景信封，随既有抬眼动作把焦点移到后景人物脸部 | 移焦是同一镜头的注意力变化，不自动新增 Shot |
| 由一个对象看到另一对象 | 摄影机原地缓慢摇向人物视线所指的门，停止时保留门和人物在画面边缘的关系 | 摇摄改变朝向；横移改变机位，两者不互换 |

景别由观看任务决定：远景/全景交代空间与完整行动，中景保留人物关系及手部，近景/特写突出既有表情、接触或细节。大景别不天然缺乏张力，特写也不能靠裁掉关键接触点完成动作。焦距只有明确的透视或背景关系需求时才写，不用精确毫米数替代画面结果。

关键手部或道具交互既要看到接触点，也要读懂谁施力、谁持物及动作结果。景别变化不能靠遮住接触、换手或物件消失来完成，复杂过程不靠切镜掩盖。人物身体、摄影机与道具各自的运动写清，不让“环绕”“转身”混成一个动作。

## 用可见效果选择质感

用光需要时说明：既有光从哪里来、如何作用于人物与物件、整体冷暖和亮暗如何组织。综合色调不改衣物与道具本色；光向跨镜有依据，不因特写就凭空增加新光源。

例如，既有窗光可以在金属杯边形成窄高光，布料保留粗糙褶皱，后景亮部较克制，使视线落在手与杯的接触上。它说明观看重点与材质响应，比同时堆“高级、大片、超清”更有执行信息。只在场景已有对应对象时采用，不把例子里的杯、窗或布料带入用户剧情。

写实、赛璐璐、水彩、产品等媒介分别选择适用的表面与成像语言。颗粒、光晕、暗角、浅景深或特定胶片观感都只是风格选项，不是画质保证；二维平涂不加入皮肤毛孔、写实PBR或无依据的复杂反光。

| 场景中已有的材质或媒介 | 可见描述短例 |
|---|---|
| 拉丝金属 | 顺着表面纹理出现窄而有方向的高光，转动时高光沿既有曲面移动，物件轮廓不融化 |
| 粗布衣袖 | 保留纤维粗糙感和既有褶皱，转腕处明暗随褶皱变化，布料本色不随调色换成另一色 |
| 玻璃杯 | 杯缘反光与透明杯壁并存，透过杯壁仍能读到后方桌面，避免把透明材质写成实心金属 |
| 木桌 | 保留现有木纹和哑光表面，接触处有符合既有光向的阴影；不自动加磨损、灰尘或水渍 |
| 赛璐璐人物 | 保持清楚轮廓、平涂色块和简洁阴影层级，不用写实毛孔或复杂皮下散射覆盖原画风 |

光色表达可写“窗侧较亮，背光侧保留可辨面部层次，衣服仍为既定本色，背景亮部不抢走手部接触的注意力”。只有原设定或参考确有窗光时才用此句。不要为追求质感增加未授权雨雪、烟雾、汗水、灯具或配乐，也不把品牌、引擎和画质形容词当作材质结果的保证。

声音仍遵守原剧情与用户要求。摄影机推近、横移或环绕不授权电机声、呼啸、转场声或配乐。参考图用于身份、服装或空间时，写清保留项与用途，不擅自把它当首帧或复制参考板的拼版布局。

## 定稿后交回H3执行

导演意图可以简短说明，随后直接交完整六段中文正文。最终正文中的镜头、动作起止和光色应与选定意图一致，不能说明写“一镜到底”，正文却出现多次Shot。实际模型、段长、引用和对白标签以h3Director为准；服务端已配置的优化流程照常执行，并保留优化前后差异。

需要从短例看到完整成稿时读 [H3 完整示例](h3Examples.md)：包含一个连续镜头和一个有明确切点的双人递物片段，并说明参考映射、原对白和独立旁白。示例中的事件与规格只在各自教学简报内成立，不能补进用户作品。
