# 云端字幕迁移与 0.6.0 托盘发布

2026-11-06 已部署。本文替代本地候选交付中“云端暂不迁移”和“真实 AI 修正未验证”的阶段状态。

## 已发布内容

- 云端保留字幕节点、字幕烧录节点、已有连线、字幕编辑及显式保存 STRING 输出；现有 `/api/whisper/check`、`start`、`task`、`cancel` 改为托盘任务协调接口。
- 服务端移除 Python、torch、CUDA、模型缓存和识别子进程逻辑。Whisper 在已选择且授权的 0.6.0 本地助手中运行；旧版助手明确提示升级，不回退服务器识别。
- 云端工作区媒体受控传给托盘，校验大小和 SHA-256；本机识别、AI 校对后回传 SRT，云端按原账户／工作区权限和文件冲突保护落盘。画布读取草稿后仍需显式保存，再向下游输出。
- 托盘硬件检测、官方环境和模型下载、本地批处理、字幕独立编辑、重新合成继续提供；站点只分发托盘程序，不保存模型或识别环境镜像。
- 网页与托盘聊天共用 localComputer 的字幕环境、扫描、提交、查询、取消和重合成动作。提交入队立即返回，关闭聊天不取消已提交任务；不通过 PowerShell 拼接字幕流程。
- AI 确定的问题自动修正；不确定项保留原文并记录，失败或超时继续处理。专用审查请求不开放文件工具，平台 Key 不下发托盘。

## 真实验证

1. 候选服务使用独立数据目录，验证“云端工作区视频 → 本机实际 Whisper → 真实账户文本模型 → SRT 回传 → 工作区文件接口读取”。14 秒视频得到 8 条字幕，AI 自动修正“尽重→净重”“长陪→常陪”。
2. 候选网页聊天实际调用 localComputer 的 subtitleStart，立即取得已落盘任务编号；工具调用结束后后台继续完成 AI 修正及 MP4 合成。
3. 显式取消回读 cancelled；跨工作区查询返回 404；已有字幕输出返回 409，未覆盖。
4. 部署后使用发布包中的真实编译 `localWorker.exe`，经公网 HTTPS 生产接口再次跑通相同链路。生产任务 `4e2379a6-1fa5-4d1b-9abb-62938695e7e5` 完成，返回 base 模型、8 条字幕、2 处实际 AI 修正；SRT 通过生产工作区接口返回 200。
5. 生产更新接口返回 0.6.0，安装包 Range 下载返回 206；节点目录回读确认 subtitleNode 仍存在且启用，默认选项 auto，已无服务器 Python 路径配置。
6. 生产容器无 Python 可执行程序，服务端运行包不存在旧 `model.transcribe` 执行代码；容器运行正常，重启计数 0。网页资源未改动。
7. 本次专用的 2 台验证设备、1 个临时会话、8 条设备调用和 1 个验证项目已按确切 ID 备份并清理。验证工作区移到发布记录目录保存；未修改客户项目。
