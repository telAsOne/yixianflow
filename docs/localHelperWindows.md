# UnionFlfow Windows 本地助手

适用于 Windows 10 / 11 x64，当前版本 0.6.3。控制中心使用 Microsoft Edge WebView2 Runtime（Windows 11 通常自带；缺少时需安装微软官方运行时）。

## 使用

1. 将压缩包完整解压到固定目录，运行 `unionFlfowHelper.exe`。保留同目录的 `localWorker.exe`、`tools/` 和许可证目录。不需要安装 Bun、Node.js 或 Python。
2. 在 Windows 系统托盘中找到 UnionFlfow 图标，打开“状态与配对码”，复制 12 位配对码。配对码 10 分钟内有效，未绑定时会自动刷新。
3. 点击助手侧栏、设备配对页或设置更新卡片中的“登录 UnionAIGC / 绑定本机”。浏览器中完成 UnionAIGC 登录后会进入“设置 → 本地助手”，输入配对码，然后在本机弹窗确认连接；已登录时直接打开绑定页。
4. 选择本机，向画布 AI 助手提出本地任务，例如读取指定文件、处理本地视频、执行指定命令或安装指定工具。AI 使用 `localComputer` 工具操作选定的电脑。
5. 双击托盘图标打开本地控制中心；托盘菜单的“本机 AI 助手”直接进入对话页。托盘仍持续接收网页任务，两种入口共用串行执行队列和确认权限。关闭控制中心只隐藏窗口，任务可继续执行；点击“停止”、暂停或退出才取消本机任务。

## 本地控制中心

- 总览展示本次运行的设备状态、执行任务、待授权操作与传输数量。
- 任务中心显示网页任务及本机对话的真实工具调用，包括排队、等待授权、执行、完成、失败与取消。详情关联脱敏运行事件，可取消单个任务；取消正在传输的任务会停止该批后续文件，已完成文件保留。
- 本机对话提供独立的历史侧栏、搜索、切换、重命名和删除；支持 Markdown、代码块、表格与消息复制，工具结果默认折叠。平台文本 Key 不进入控制中心或托盘。
- 文件传输显示逐文件已传字节、平均速度与估算剩余时间；文件确认阶段单独显示，网络传输结束不直接认定成功。暂不提供暂停续传或自动重试。
- 设备与连接保留配对码、绑定状态、复制配对码和解除绑定。审批、自动执行与解绑使用本机控制中心的统一确认弹框，原生桥核对待审批编号后才把决定交给工作进程。关闭或超时仍视为拒绝。
- 工具环境只按用户操作检测实际工具路径，不自动安装软件或模型，不把找到路径当作运行验证。
- 日志中心筛选、搜索最近 300 条脱敏事件，支持暂停界面刷新与打开原日志文件夹；暂停刷新不影响磁盘日志。历史日志规则保持不变。
- 设置保留开机启动、暂停接收并取消运行任务、重新启动已停止进程和日志入口。
- 界面从安装包的 `ui/` 本地资源加载，不监听本机端口，不加载网页脚本。原生桥仅接受指定控制命令；审批、自动执行与解绑继续使用本机确认。
- 任务与传输列表保存在本次工作进程内存中。聊天正文和模型上下文单独存入原数据目录的 `chats/<账户隔离目录>/`，完整快照原子保存，重启并确认同一绑定账户后恢复。新建会话不清除旧会话；删除会话不删除文件操作结果或诊断日志。旧版未落盘的内存聊天不能补回。
- 此次交付 Windows 控制中心与共享 Vue 页面；macOS 托盘、系统操作适配和安装包尚未完成。

## 文件工具与智能体

- 网页 AI 和托盘智能体使用相同的 `localComputer` 工具清单与参数描述，包含 `readBatch`、`projects`、`upload`、`download`，无需让模型猜测能力。
- `readBatch` 每次最多 20 个文件，合计最多读取 256 KiB；按各项返回的 `nextOffset` 与 `revision` 判断是否读完。原 `read` 单次仍最多 64 KiB。
- `projects` 只列当前绑定账户的网页项目。上传和下载显式传 `projectId` 与 `files`，本机使用磁盘绝对路径，项目内使用相对路径，不接受服务器绝对路径或任意下载地址。
- 上传下载每次最多 20 个文件，单文件最多 100 MiB，整批最多 200 MiB。托盘预检和服务端均限制大小与数量，逐文件流式传输，不自动拆批绕过限制，不递归上传整个文件夹。
- 上传下载只新建文件，目标的父文件夹须已存在。批次开始前预检文件及目标；执行中失败保留已完成项并返回逐项结果，不覆盖原文件，不自动重传。取消或失败的临时文件会清理。
- 独立聊天使用绑定账户的默认文本模型和同一授权 Key，由平台代理模型请求；Key 保留在平台，不下发到托盘，也不需要另填。文本请求沿用账户的模型权限及计费。
- 智能体的工具执行循环在托盘内，每轮最多 20 次工具调用。对话请求最多 1 MiB；每份本机会话文件最多 4 MiB，达到上限时提示开始新对话，不静默删除历史。聊天内容及工具输出保存在本机独立会话文件中，不进入诊断日志，不新增服务端聊天文件或正文缓存。恢复中断会话时补齐“结果未确认”的工具回执，不自动执行原操作。

## 批量字幕与云端画布

托盘支持独立批处理，云端画布保留字幕及字幕烧录节点。Whisper 识别只在本机执行，云端负责鉴权、协调、素材传输和保存返回的 SRT，不安装 Python 或模型。

1. 打开“批量字幕”，点击“检测本机环境”。程序读取 GPU／NVIDIA 驱动和可用显存、CPU、当前可用内存、目标磁盘空间；不把 AMD／Intel 显存当成 CUDA 能力。默认按资源推荐模型，支持手动选择资源允许的模型。
2. 首次打开自动检查本机环境。Python 和模型路径可以留空：程序先检查独立环境、系统 PATH、Python 启动器、注册表、Conda 清单、常用虚拟环境和模型缓存；未找到可用组合时继续搜索本机磁盘，验证识别依赖与官方模型 SHA-256 后直接复用。自动搜索最多 15 秒，平分各磁盘的目录与条目预算，跳过系统目录、依赖目录和符号链接，最多搜索 10 层；未覆盖的位置会明确提示，可重新检测或通过原生文件／文件夹窗口选择。支持当前列表中的 OpenAI Whisper `.pt` 权重，其他引擎的模型格式不能直接使用。
3. 没有可用环境或所选模型时，点击“一键准备环境与模型”。程序只补齐缺少的部分，使用官方源，不修改系统 Python 或 PATH。成功发现的路径单独保存在当前电脑数据目录的 `whisperDiscovery.json`，重启后重新验证并复用；分发包不包含个人设置、设备绑定、任务或检测缓存，每台电脑独立发现和安装。
4. “选择视频”或“扫描文件夹”，可勾选包含子文件夹。确认本批最多 400 个视频后开始；每个视频形成持久任务，单条失败不阻塞其他条目。输出另存到源视频旁，不覆盖原视频。
5. AI 能确定的问题自动修正；不确定项保留原文并记录。未绑定账户、审查失败、超时等均记录并继续处理。AI 使用绑定账户文本模型的专用字幕审查请求，不开放文件工具，Key 仍留在平台。
6. “字幕／记录”中编辑开始／结束秒数和文字，保存本页，再点击重新合成。重新合成使用原视频与保存稿，不重复识别或收费审查；旧视频版本保留。关闭控制中心窗口继续执行，退出后保留记录；重开可以继续未完成任务。
7. 托盘“本机对话”可输入 `给 "F:\视频\片段.mp4" 生成字幕`，或带引号的文件夹路径，直接创建本机任务；网页聊天使用 localComputer 的 subtitleStart 等动作操作当前选择的电脑。关闭聊天不取消已入队任务；明确取消使用字幕任务取消入口。
8. 云端画布连接视频或音频到字幕节点，生成时将素材交给选定助手识别，自动校对后返回 SRT 草稿，显式保存再更新 STRING 输出。单个素材沿用现有 100 MiB 传输上限，超出时明确提示。识别完成但回传失败时保留本机字幕，重连只重传结果。原字幕编辑、导入和下游连线继续可用。

本机独立任务可离线识别和合成；AI 审查需要有效账户连接。AMD／CPU 安装、真实视频和绑定账户 AI 修正／SRT 回传已验证；NVIDIA／CUDA 及原生文件框／编辑操作仍需对应环境验收。视频预览使用当前任务的单独副本与受控映射，不开放整块磁盘。

## 权限与运行

- 操作权限与当前 Windows 用户相同，可访问其有权访问的本机磁盘；不自动提权，不通过本机网络端口开放控制接口。
- 连接时会在本机确认文件读取权限。读取的内容及命令输出会经平台用于 AI 对话。
- 写入、覆盖、移动、删除、上传下载、PowerShell 命令和软件安装默认逐次在本机确认；150 秒未确认视为拒绝。覆盖文件需先读取最新版本。目录每页 200 项。
- “本次运行自动执行文件操作和命令”需从托盘显式开启，退出助手后失效。暂停会停止接收，并终止正在运行的本机进程树；退出也会终止子进程。
- 解除绑定立即撤销设备权限。沿用现有 AI 对话的取消语义：关闭网页、对话连接中断或主动停止会取消本机调用。取消、重启、断网及回报失败不会自动重跑原命令；网络恢复只重传已保存的结果。
- 每台设备串行执行，队列上限 20 项。命令默认 60 秒，安装默认 20 分钟，可按调用设置至多 20 分钟。命令输出有大小限制，超出时返回截断标记。
- FFmpeg 与 ffprobe 6.1.1 随包提供，不修改系统 PATH。画布音视频处理、字幕烧录、Agent/供应商的 FFmpeg 工厂、媒体探测及缩略图均通过当前网页登录会话选定的助手执行；服务器只协调任务与素材传输，不运行 FFmpeg/ffprobe。0.6.0 起 Whisper 识别也全部由助手执行，环境和模型在托盘配置。
- 设置 → 本地助手显示本机 FFmpeg 组件状态并提供修复安装；插件市场不再设置独立 FFmpeg 页签。未连接、暂停、未授权或版本过旧时明确报错，不回退到服务器。网页工作区输入下载到独立缓存目录，输出经大小和 SHA-256 校验后以排他方式保存到原工作区；结果全部上传后才回报完成。每次传输输入、输出各最多 20 个文件，单文件最多 100 MiB、整批最多 200 MiB，不自动拆批，不覆盖已有输出。直接指定的本机文件无需先上传。
- 同一助手串行执行媒体和本机工具任务。取消、切换设备、退出登录或任务超时会撤销素材与输出许可，并在助手心跳时终止本机进程；重连只重传任务结果，不自动重新编码。当前媒体传输许可随服务器重启失效，不支持关闭页面后恢复进度、断点转码或自动重试上传。正常完成、失败及取消后清理该任务缓存。
- FFmpeg 按当前 Windows 用户权限读取本机素材，不额外设置媒体格式白名单或缓存目录读取沙箱。Windows 绝对输入路径直接在本机读取，绝对输出路径保存到本机；相对路径继续代表网页工作区素材。本机绝对 `cwd` 切换整条命令到该本机目录，输入、清单及滤镜可以引用当前用户有权访问的本机文件。
- 软件安装通过 Windows `winget` 按精确包 ID 安装，使用当前用户范围。缺少 winget 时请通过 Microsoft Store 更新“应用安装程序”。其他已安装工具可通过 PowerShell 调用。
- 托盘可设置开机启动。请先将解压目录放在固定位置，移动目录后重新设置开机启动。
- 设备凭据、待回传结果与操作摘要保存在 `%LOCALAPPDATA%\UnionFlfow\localHelper`；操作摘要不记录完整文件内容、命令正文或凭据。
- 此版本没有屏幕截图、鼠标点击和键盘代输工具；可通过文件、PowerShell 与程序调用完成本机操作。系统及应用的权限要求仍由 Windows 决定。

## 本地诊断日志

- 托盘菜单的“打开日志文件夹”可直接查看，默认目录为 `%LOCALAPPDATA%\UnionFlfow\localHelper\logs`；设置 `TOONFLOW_HELPER_DATA_DIR` 时随数据目录移动。
- 按本机日期分目录，文件名带时间、进程及分段编号，例如 `2026-11-03/2026-11-03_01-23-45_123_worker_1234_1.log`。每份最多 16 MiB，满后创建新文件；记录中的 `at` 使用 UTC 时间，方便关联服务器日志。
- 跨天后自动把上一天的日志压缩成日期命名的 ZIP，归档完成并确认文件未变化后才移除原 `.log`。同一天日志较多时会分成多个 ZIP，不按总大小或份数删除。
- 日志及归档仅按时间保留：某个日志日期结束满 7 天后清理。启动时补做归档和清理，运行期间每分钟检查一次；助手未运行时不执行后台清理。
- 记录启动退出、断线重连、授权和暂停、任务编号、操作阶段、HTTP 状态、错误分类与系统代码、调用栈位置、传输数量及耗时。工作进程异常退出后，托盘会调用独立日志模式补记退出信息。
- 不记录 Key、设备令牌、配对码、文件正文、聊天内容、命令正文或命令输出；异常正文也不落盘。日志仅保存在本机，查看文件夹不会自动上传。
- 升级后不再续写旧的 `activity.jsonl`，原有摘要保留。排查问题时可提供对应日期的 ZIP。

## 自动与手动更新

- 设置中的“检查更新”读取当前平台发布的助手版本；手动下载后校验 ZIP 的 SHA-256、大小、所有程序文件的摘要及安全路径，再允许“安装并重启”。
- 自动检查默认开启，绑定并授权连接后每小时检查一次。空闲时自动更新默认关闭，开启前会弹框确认之后的下载、安装和重启行为；设置保存在原数据目录的 `updatePreferences.json`。
- 当前有本机任务、对话、会话切换、解除绑定或待回传结果时，不执行自动安装。自动更新失败后停止本轮自动重试，保留明确错误供手动处理。
- 更新器在独立进程中验证候选程序，发出就绪回执后原托盘才退出；原进程未退出时不替换文件。更新器保留上一版本，等待新工作进程启动确认，替换失败或新进程启动失败时尝试恢复原程序；回滚也失败时明确提示并保留备份。
- 程序更新不迁移或删除设备身份、会话及日志。自定义数据目录若位于待替换的程序目录内，会拒绝自动更新；先移到独立目录并沿用 `TOONFLOW_HELPER_DATA_DIR`。
- 更新通过当前平台的设备 Bearer 凭据访问 `/api/localHelper/device/update` 和 `/api/localHelper/device/updatePackage`，设备须已绑定账户，不接受浏览器 Cookie、Origin 或任意外部下载地址。
- 发布时把匹配版本的 `unionFlfowHelper.zip` 与构建生成的 `download.json` 一起放进服务端 `downloads/`，或使用 `TOONFLOW_LOCAL_HELPER_PACKAGE` 指定 ZIP，清单仍与 ZIP 同目录。服务端核对 ZIP 摘要后才对设备发布版本；只更新服务器源码版本号不会让客户端误报更新。`download.json` 可另加 `notes` 字段提供不超过 6000 字符的更新说明。
- 需要同时发布新增服务端更新接口和包/清单，线上客户端才能下载。0.3.0 及更早版本没有内置更新入口，首次升级到此版本仍需完整解压新包。

## 开发与发布

使用根 `package.json` 指定的 Bun 1.3.14，在 Windows x64 执行：

```powershell
bun run --cwd apps/localHelper typecheck
bun apps/localHelper/scripts/prepareWindows.ts
bun apps/localHelper/scripts/build.ts F:/workspace/yixianflow/build/localHelper
```

`prepareWindows.ts` 是显式的 SDK 准备步骤，从微软 NuGet 下载固定版本 WebView2 SDK 并校验 SHA-256；构建不会隐式下载该 SDK。目标目录必须不存在。构建生成 `unionFlfowHelper.zip`、下载摘要与包含程序、界面资源和 WebView2 组件摘要的 `manifest.json`。媒体工具安装复用 `@toonflow/ffmpeg` 的固定版本及 SHA-256 校验。可使用 `unionFlfowHelper.exe --controlCenter` 在启动托盘后打开控制中心。

服务器使用现有网页版 PostgreSQL 存储设备及任务，启动时建表。把压缩包放到服务数据目录的 `downloads/unionFlfowHelper.zip`，或将 `TOONFLOW_LOCAL_HELPER_PACKAGE` 设置为压缩包绝对路径；前端从受登录保护的 `/api/localHelper/download` 下载。`/flow/` 子路径由现有代理保持，设备接口使用独立 Bearer 凭据。

本地助手通过 HTTPS 主动轮询平台；无需开放本机防火墙端口。设备绑定归属账户，网页会话单独选择设备。每次工具调用固定设备与网页登录会话，退出登录、撤销设备或取消调用后停止授权。已领取任务不会自动重新入队，意外中断时需用户核对实际状态再发起新操作。

FFmpeg 许可证和上游构建说明在 `licenses/`。对应上游版本、构建配置及源代码入口：

- https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1
- https://www.gyan.dev/ffmpeg/builds/
- https://ffmpeg.org/download.html

Bun、WebView2 SDK 与项目许可证亦在 `licenses/`，Windows 原生托盘使用系统 .NET Framework、Windows Forms 和 Edge WebView2 Runtime。升级时退出旧托盘、完整解压新包；不删除或移动原设备数据与日志目录。
