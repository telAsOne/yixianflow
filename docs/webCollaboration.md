# 网页项目协作

在「设置 → 项目成员」统一管理邀请、成员权限与最近操作。项目顶部只显示在线人数和会话数，点击可进入该设置页。AI 面板按成员分别保留聊天历史和上下文，不提供成员群聊。

项目管理员（项目所有者）可以在「设置 → 项目成员」创建供一人使用的邀请链接，选择「可编辑」或「仅查看」。链接七天有效，接收者使用自己的 UnionAIGC 账号登录后确认加入。项目管理员可以调整成员权限、移除成员或撤销尚未使用的邀请。UnionAIGC 管理员访问他人项目时，进出不写入项目动态，在线状态、光标和 AI 操作状态对非平台用户隐藏。在自己创建的项目中，作为项目管理员正常显示身份、在线状态、光标和协作状态。

UnionAIGC 管理员不通过邀请成为项目成员，也不占用邀请链接；访问他人项目直接使用平台权限。平台管理员可以创建项目，在自建项目中同时拥有平台管理权与项目所有者权限；两种权限分别判断，项目权限不会降低平台权限。普通成员后来升级为平台管理员时，原成员权限不再决定其访问能力，也不再显示为受邀成员；已有邀请使用历史保留。平台管理员的个人 AI 对话、历史及操作记录在自建或他人项目中都只对平台管理员开放。

同一画布显示成员姓名、彩色光标和选中节点。成员面板提供视角跟随，用户主动操作画布后退出跟随。AI 执行时显示所属成员和当前状态；最近操作可定位到画布和节点。

普通成员只能读取自己的 AI 对话。项目管理员可以在「AI 助手 → 成员 AI 记录」按成员查看本项目非平台管理员的对话及历史，包括更早的消息和子 Agent 对话；运行中的回复会自动更新。UnionAIGC 管理员可以查看所有成员记录，其自己的对话、历史和项目内个人 AI 文件不对非平台管理员开放。此规则同时约束成员列表、直接读取接口和 AI 工具。查看记录不会切换调用身份，也不提供代发、停止、删除或回答他人提问的操作。成员退出后，已有对话仍保留在该项目的历史中。个人 AI 会话、提问回执和恢复草稿按账号隔离；写入画布的作品由项目成员共享。

管理员自己的 AI 同样拥有读取能力：项目管理员可以读取自己管理项目中非平台管理员的成员对话、历史、子 Agent 记录、项目文件、画布、素材与操作记录；UnionAIGC 管理员可以跨所有项目查阅全部成员记录。AI 使用 `projectRead` 查询成员和记录，按需分页读完内容。各成员的对话继续分别保存，读取不会把其他人的聊天自动拼进所有成员的上下文。每次读取重新校验登录、平台身份和项目管理权限。历史平台操作记录保留，仅平台管理员可查阅；共享画布和作品的实际修改仍正常同步。

同一账号允许多个浏览器或设备同时登录与操作，各窗口分别保留视角、选区和输入草稿。不同节点或字段的修改按现有规则合并，同一内容冲突时保留草稿并提示处理，不静默覆盖。一个账号的多个连接计为一人，在线会话分别计数；另一窗口的光标显示「我 · 另一窗口」。同一个 AI 对话的执行沿用服务端文件锁，生成和计费仍归发起账号。退出登录只退出当前浏览器；「设置 → UnionAIGC 账户 → 登录设备」可主动退出其他浏览器的登录。

网页协作不要求安装本地助手。调用本机目录、命令、FFmpeg 等能力的成员，在自己的电脑安装并绑定助手。项目成员权限不会授予其他成员设备的控制权。现有图片、视频任务仍绑定原发起者的调用身份，其他成员可以查看项目中的进度和成品，恢复原任务需要原发起身份。

开发与部署约束：

- 身份、平台角色、模型调用及计费沿用 NewAPI；项目成员和操作记录存储在 Flow 的 PostgreSQL 中。
- 网页通过事件流接收更新，断线重新读取画布；原有轮询仍用于补偿同步。首页恢复焦点及可见期间会刷新项目列表。
- 当前画布文件锁、在线状态和事件转发均为单进程。部署多个实例前，需要一起处理文件写入协调与共享事件通道。
- 旧的项目聊天及恢复记录会保留并迁至原所有者的用户目录。素材回收仍检查各成员的个人上下文与恢复记录中的引用。
- 发布需要同步更新网页、服务端与文本节点插件。类型检查和构建不能替代双账号浏览器及真实设备验证。
