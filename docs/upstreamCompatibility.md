## 已兼容的改动

| 改动 | 价值与本次适配 |
| --- | --- |
| 项目 ZIP 导出 | 工作区顶部增加导出入口，导出前保存画布、文档和设置；复用 `useWorkspaceFiles` 与现有文件保存入口。保留上游 1 GB、10000 项限制，服务端改用 64 KiB 分块读取、压缩和响应背压，保留空目录与中文文件名。沿用工作区权限、真实路径和符号链接校验，检测导出期间的文件变化。桌面与移动端接收上限同步为 1 GB。 |
| 复制节点后的素材引用 | 提取并复用上游 `remapNodeReferences`，同时覆盖画布复制、剪贴板粘贴和批量创建副本；引用列表与提示词标签指向复制后的新节点，未复制的外部引用保持原样。 |
| 提示词引用菜单 | 将菜单挂到编辑器所在弹窗中，展开、收起时重新定位挂载点。保留当前版本的分组引用、光标恢复与撤销适配，没有整体替换输入组件。 |
| 框选状态残留 | 扩充已有 Vue Flow 补丁，开始新框选时清空内部节点、连线选中集合；保留当前补丁中的节点查找性能优化。 |
| 鼠标侧键与 Linux 中键 | 在工作区拦截侧键的原生历史导航；画布中键事件阻止系统剪贴板粘贴，同时保留中键拖动画布。 |
| Agent 空画布上下文 | 接口允许空画布 ID，避免没有打开画布的调用因这一字段被参数校验拒绝；继续保留逸仙账户校验与本机文件授权。 |
| 文档面板初始化 | 等待历史标签与布局恢复完成，再向工作区控制调用开放文档读写，避免刚打开面板就读取尚未恢复的状态。 |
| 错误解释 | 支持手动选择解释模型，保留逸仙账户模型来源；区分原始错误与解释请求失败，提示词要求明确区分事实、推测，不仅凭状态码建议充值。 |
| 文件写入锁 | Bun 写入数组时固定数组快照，并收集所有文件成员的锁路径，避免排队期间成员变化或遗漏源文件锁。 |
| 目录读取取消 | 将取消信号传到统一文件入口的排队控制中，取消后不继续等待目录访问。 |
| Windows 更新重试 | 更新助手未成功启动时保留已经校验的更新包，并展示助手标准错误中的具体原因；保留当前便携启动器的交接协议、更新源、校验与失败回滚逻辑。 |
| WebView2 版本比较 | 采用微软 `CompareBrowserVersions`，避免 beta/dev/canary 后缀被通用版本解析器误判；不引入新版安装探测界面和额外 SDK。 |

## 上游其他更新的取舍

| 更新 | 本次判断 |
| --- | --- |
| macOS 实体 Ctrl 滚轮修复 | 当前分支已采用独立的像素归一化、捏合判断和逐帧缩放，不再使用出问题的 `wheelDelta` 路径，保留现有实现。 |
| 首页、画布布局、素材库和节点菜单重做 | 当前分支已有左侧创作栏、快速开始、右下导航、节点面板与协作状态等独立改进，保留当前交互；不以整页覆盖的方式移植。 |
| Agent 消息队列、队友协作 | 有实际价值，但涉及会话存储、请求与事件协议、Pi Agent 依赖补丁及输入组件重组。当前版本另有本机文件授权、会话索引和逸仙请求逻辑，本轮未移植这一整套协议。 |
| 代码沙盒、MCP 客户端管理、网络代理 | 有价值，但会扩展代码执行、外部工具连接或全局网络请求范围，需要按当前权限与账户链路分别适配，本轮未引入。 |
| PDF/Office 文档解析 | 可改善 Agent 附件能力，但需要增加 AnyDoc/WASM 依赖以及相应构建分发，本轮未增加这些依赖。 |
| 语音输入、浏览器音频转写、逐帧拉片 | 属于新增完整功能；当前分支已有本地 Whisper 与媒体工具适配，本轮未替换原音频链路或新增拉片节点。 |
| 第三方供应商、媒体估价与余额展示 | 上游围绕多个第三方供应商实现；当前分支已收敛为逸仙托管模型，保留当前供应商、模型同步、Gemini 生图、H3/U00N 与任务恢复逻辑。 |
| 模型上下文别名、思考档位与自定义供应商编辑 | 上游同时调整模型配置结构和 Agent 模型初始化。当前账户下发模型与请求预算另有适配，本轮保留其行为，未仅复制模型目录或放宽请求参数。 |
| v1.1.8 分集制作 Skill | 内容值得参考，但其工作流与上游节点、工具接口绑定；本轮未将其作为已经适配的内置技能分发。 |
| Windows 兼容启动、归档工具与安装器重做 | 与当前便携版的目录、启动器、更新交接和发布流程存在差异，仅移植可独立验证的版本比较与更新重试修复。 |
| Mac 镜像卸载、签名、Android GeckoView、鸿蒙 | 平台相关改动较多，且当前分支已有双架构 Mac 和便携版发布适配；本轮没有修改这些发布流程，也没有将未完成的鸿蒙适配引入。 |
| Bun 1.4.3 与其他依赖补丁 | 继续使用项目固定的 Bun 1.3.14，保留已有 Anthropic Schema 补丁；只刷新 Vue Flow 的现有补丁，没有新增依赖或升级版本。 |
