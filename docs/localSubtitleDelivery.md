# 本地批量字幕候选交付

日期：2026-11-06。本阶段只修改本地托盘能力，保留当前云端识别实现、画布字幕节点和字幕烧录节点；不部署、不切换云端。

## 已实现

- 检测 CPU、物理可用内存、GPU、NVIDIA 驱动和当前可用显存、缓存盘及视频输出盘剩余空间。默认自动推荐模型，不默认下载所有权重或最大模型；AMD／Intel 不误判成 CUDA。
- Python、Whisper、PyTorch 与模型全部由本机访问对应官方来源；独立安装目录，不修改系统 Python／PATH，站点不留镜像、不转发下载。Python、pip、Whisper 源码包及权重校验固定 SHA-256；模型与引导包有缓存和续传。
- 选择视频、扫描目录和可选子目录，每批最多 20 个视频，逐视频持久任务、串行处理、去重、取消及重启后恢复记录。
- Whisper 识别、AI 确定修改自动应用、不确定项记录；未绑定文本账户、审查失败或超时保留当前字幕并继续合成。
- 字幕按页独立编辑、保存修订和重新合成。始终使用原视频，不覆盖源文件和旧成片，SRT／MP4 保存到源视频旁；失败及取消保留旧结果。
- 托盘本机聊天支持带引号的文件／目录指令创建后台任务。网页 AI 的字幕专用工具和云端节点计算迁移留待第二阶段。

## 实际验证

1. 在 AMD Radeon RX 6750 GRE／i5-13600K 机器读取实际硬件和盘符；根据当时约 4 GiB 可用内存推荐 base，未安装 CUDA。
2. 在 F 盘隔离数据目录完成官方 Python 3.12.10、Whisper 20250625、CPU PyTorch 2.7.1 安装，以及 base 权重下载和完整摘要校验。base 权重为 145,262,807 字节；该次独立识别目录合计约 1.73 GB，这是落盘体积，不是网络下载量。
3. 经用户授权从生产服务器只读下载 3 个已有视频副本，全部完成本机识别、SRT 生成、FFmpeg 烧录并保存旁边 MP4。测试过程中未发起新的付费视频生成。
4. 其中一段 14.375 秒视频识别出 8 条中文字幕。手动将“尽重”改为“净重”、“长陪”改为“常陪”，保存第 2 版后只重新编码，旧版 MP4／SRT 保留。抽帧可见“净重18.8公斤”，新成片完整解码无 FFmpeg 错误。
5. 新进程重新读取任务，恢复第 2 版、8 条字幕和两次成片记录；取消后仍保留既有字幕和旧成片。无有效语音素材记为“无可识别字幕”，不生成空成片。
6. 对本轮编译的候选 `localWorker.exe` 直接发送正式控制协议：保存设置 → 扫描 → 创建任务 → 识别 → 实际未绑定账户的审查降级 → 合成 → 正常退出，真实完成且退出码 0。
7. localHelper 和字幕插件已有 typecheck 通过；原生 C# 编译、Vue 构建、Bun worker 编译和首个完整 Windows 打包通过。最后补充恢复校验后的构建在远程许可证下载发生 ECONNRESET；最终包核对 FFmpeg／ffprobe、WebView2 组件与该轮成功包摘要一致后，复用其许可证完成清单及 ZIP，不能将最后一次构建表述为脚本全程无故障。浏览器只核对无原生桥的页面布局，不计作原生交互验收。
